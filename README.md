# SDGSAT-1-GLI-chromaticity-and-CCT-derivation
This repository contains data supporting the research paper "Approximating the chromaticity and correlated colour temperature of nighttime light sources based on SDGSAT-1 glimmer data" by Nijun Jiang, Changyong Dou, Yunwei Tang, Mingyang Lv, Xinhong Zhang, Lei Peng, Lin Yan, Haifeng Ding and Hao Zhang.

"Simulated_Response_CIEXYZ.csv" contains simulated CIE XYZ readings

"Simulated_Response_GLIRGB.csv" contains simulated GLI RGB readings

"validation_geotiff_files.zip" contains 125 GLI raster subsets clipped according to the ground sampling locations

"Summary_of_measurement_data_against_predications.xlsx" contains 1. average in-situ measurement of chromaiticty x and y for each sampling location 2. predication of chromaiticty x and y for each sampling location based on GLI subset 3. ground reflectance and atmospheric atmospheric transmittance applied for each GLI subet.
