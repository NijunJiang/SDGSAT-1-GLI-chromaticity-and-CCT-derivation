# SDGSAT-1-GLI-chromaticity-and-CCT-derivation
This repository contains data supporting the research paper "Approximating the chromaticity and correlated colour temperature of nighttime light sources based on SDGSAT-1 glimmer data" by Nijun Jiang, Changyong Dou, Yunwei Tang, Mingyang Lv, Xinhong Zhang, Lei Peng, Lin Yan, Haifeng Ding and Hao Zhang.
